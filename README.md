
# Emprega Perto

**Sistema de oportunidades de emprego para candidatos e empresas próximas.**

## Sobre o projeto

O Emprega Perto é um sistema desenvolvido em Java com o objetivo de aproximar candidatos e empresas, facilitando a busca por oportunidades de emprego em sua região.

A plataforma permite o cadastro de candidatos e empresas, a publicação de vagas e a realização de candidaturas. Além disso, utiliza informações de localização para identificar oportunidades no mesmo bairro, na mesma cidade ou em outras localidades.

## Funcionalidades

- Cadastro de candidatos;
- Cadastro de empresas;
- Cadastro e publicação de vagas de emprego;
- Busca de oportunidades por localização;
- Comparação entre bairros e cidades;
- Realização e acompanhamento de candidaturas.

## Estrutura do projeto

O sistema foi desenvolvido utilizando os conceitos de Programação Orientada a Objetos (POO), organizando suas funcionalidades nas seguintes classes:

| Classe | Responsabilidade |
|---|---|
| `Perfil` | Classe abstrata com os dados básicos de candidatos e empresas. |
| `Candidato` | Representa os usuários que procuram emprego. |
| `Empresa` | Representa as empresas cadastradas. |
| `VagaEmprego` | Armazena as informações das vagas publicadas. |
| `Candidatura` | Gerencia as candidaturas realizadas. |
| `Localizacao` | Armazena e compara os dados de localização. |
| `Main` | Executa o sistema e apresenta o menu de interação. |
